## 🧠 Learning Approach

For each major algorithm, I focus on understanding:

1. **What problem does it solve?**
2. **How does it work internally?**
3. **What are its important hyperparameters?**
4. **What are its advantages and limitations?**
5. **When should it be used?**
6. **How is its performance evaluated?**
7. **How does it compare with other algorithms?**

The repository combines **conceptual learning, Python implementations, experimentation, and model comparison**.
